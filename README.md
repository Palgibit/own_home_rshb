# «Своё Жильё»: путь к своему дому

Решение кейса **«Своё Жильё»** для стипендиальной программы РСХБ.Цифра 2026–2027, направление «Информационные технологии».

**Сайт:** https://palgibit.github.io/own_home/
**Код:** https://github.com/Palgibit/own_home

> Демо-прототип для конкурса РСХБ.Цифра. Не является официальным сервисом банка. Все ставки и цены условные.

## Идея

Три задачи кейса решены не тремя отдельными калькуляторами, а одним путём клиента:

```
Навигатор (до сделки)  →  Симулятор (решения)  →  Жизнь после ипотеки (кабинет)
```

- **Сельская ипотека, дом, участок и ИЖС — главные сценарии**, а не дополнение к городской квартире. Это продолжение миссии банка «И к селу, и к городу».
- **Прозрачность.** Любое число можно нажать и увидеть формулу, подставленные значения и пояснение простым языком.
- **Ничего не захардкожено.** Ставки, лимиты, сценарии, формулы, шаги навигатора и подсказки хранятся в конфиге и меняются в админке.

| Задача | Где | Что сделано |
|---|---|---|
| 1. Симулятор «Что, если…?» | `#/simulator` | Досрочный платёж (два режима), кредит на ремонт, сдача в аренду, потеря льготы; «было → стало» по платежу, сроку, переплате, бюджету и ПДН; график остатка долга |
| 2. Навигатор «Путь к своему дому» | `#/navigator` | Маршрут собирается из шагов с условиями показа по ответам на 4 вопроса; матрица «шаг × сценарий» |
| 3. «Жизнь после ипотеки» | `#/after`, `#/after/cabinet` | Гость: демо-данные или ручной ввод. Клиент: данные из «банка», персональные напоминания |
| Админка | `#/admin` | Параметры, сценарии и формулы с живым предпросмотром, подсказки, шаги навигатора, экспорт и импорт |

## Что сверх задания

1. **«Досрочка или вклад?»** Калькуляторы обычно советуют гасить досрочно. При сельской ипотеке под 3% деньги выгоднее держать на вкладе: на стартовых значениях вклад выигрывает 274 455 ₽. Если клиент **теряет право на льготу** и ставка растёт до 18,7%, вывод меняется: досрочка выгоднее на 409 193 ₽.
2. **«Город или село».** Сравнение на одинаковых условиях: квартира в городе по рыночной ставке против дома с участком по сельской ипотеке. Пример на стартовых значениях: 39 м² и платёж 76 675 ₽ против 110 м² и 26 621 ₽.
3. **Досрочка «чашкой кофе».** Доплата 3000 ₽ в месяц закрывает кредит на 2 года 2 месяца раньше и экономит 234 101 ₽. Работает и обратный вопрос: «хочу закрыть за 15 лет — сколько доплачивать?»
4. **Реальная стоимость платежа.** Те же 33 276 ₽ через 10 лет весят как 17 894 ₽ сегодняшних, если инфляция 6,4% (это допущение, а не прогноз).
5. **Кликабельные цифры** во всех модулях: формула, подстановки, пояснение.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # локальный сервер разработки
npm test         # тесты расчётного ядра и админки (Vitest)
npm run build    # сборка в dist/
```

При каждом push в `main` GitHub Actions собирает сайт и публикует его на GitHub Pages ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

## Как устроено

Статический сайт без сервера: все расчёты идут в браузере. Стек: Vite, React, TypeScript, mathjs, Recharts и Vitest.

```
src/
  core/      расчётное ядро: чистые функции без React и браузерных API, покрыто тестами
  config/    default.json (все ставки, сценарии, формулы, шаги, подсказки), схема и проверка, хранение
  data/      источники данных о кредите: гость (демо или ручной ввод) и имитация «банковского контура»
  modules/   simulator, navigator, after, admin
  ui/        общие компоненты: ExplainableNumber, поля ввода, форматирование
```

**Ядро изолировано.** `core/` ничего не импортирует из интерфейса, данных и браузера. Его можно вызвать из теста или консоли. Модуль 3 считает досрочку тем же ядром, что и симулятор.

**Каждое число несёт объяснение.** Функции ядра возвращают не просто число, а `Explained`: значение, ссылку на формулу в конфиге и подставленные значения. По нему компонент `ExplainableNumber` показывает поповер «откуда это число». Текст формулы и подсказку редактирует админ.

**Сценарий — это набор формул.** Сценарий симулятора в конфиге описан параметрами и эффектами: разовый досрочный платёж, месяц, доплата, новая ставка, дополнительный доход и т. д. Каждый эффект — формула над переменными кредита (`S, rate, n, i, P, income, expenses`), глобальными параметрами и параметрами сценария. Поэтому новый сценарий появляется без изменения кода.

**Формулы безопасны.** Формулу разбирает mathjs, а вычислитель пропускает только белый список конструкций: числа, известные переменные, арифметику, сравнения, условие `?:` и несколько функций, включая `annuity(S, rate, n)`. `eval` не используется.

**Навигатор — три оси, а не семь сценариев.** Объект, цель и финансирование — независимые оси, а маршрут — это шаги, условия которых совпали с ответами. Недопустимые сочетания задаются в конфиге. Например, сельская ипотека не выдаётся на вторичную квартиру или на участок без стройки. Матрица строится тем же кодом, что и маршрут, поэтому всегда с ним совпадает.

**Гость и клиент — один интерфейс.** Блоки модуля 3 получают данные через `DataSource` и не знают, откуда они пришли: из демо-кредита, ручного ввода или имитации банка.

### Основные формулы

| Величина | Формула |
|---|---|
| Месячная ставка | `i = rate / 12 / 100` |
| Аннуитетный платёж | `P = S·i / (1 − (1 + i)^(−n))` |
| График | проценты = остаток · i, тело = P − проценты |
| Переплата | `P·n − S` (с досрочками — сумма процентов по графику) |
| Свободный бюджет | `доход − расходы − все платежи` |
| ПДН | `все платежи / доход`: до 30% зелёный, 30–50% жёлтый, больше 50% красный (пороги в конфиге) |
| Доход по вкладу | `X · ((1 + d/12)^m − 1) · (1 − налог)` |
| Экономия от досрочки | проценты без досрочки − проценты с досрочкой за тот же горизонт |
| Доплата под желаемый срок | `P(n_цель) − P` |
| Реальный платёж | `P / (1 + π)^t`, где t — годы |
| Аренда | `аренда · (1 − налог) − расходы − аренда · доля простоя` |
| Налоговый вычет | `НДФЛ · min(стоимость, 2 млн)` + `НДФЛ · min(проценты, 3 млн)` |

## Сценарий демонстрации для жюри

**1. Навигатор** — `#/navigator`
- Выберите типовой сценарий «Сельская ипотека: стройка»: в маршруте 20 шагов, среди них проверка населённого пункта, требования к работе и регистрации, срок стройки 24 месяца.
- Переключитесь на «Квартира в новостройке»: шаги про сельскую ипотеку уходят, появляются проверка застройщика и приёмка квартиры. Над таймлайном показано, сколько шагов добавилось и сколько ушло.
- Вкладка «Шаги × сценарии» (`#/navigator?view=matrix`) показывает все шаги по всем восьми сценариям на одном экране.

**2. Симулятор** — `#/simulator`
- Нажмите на любой результат и посмотрите формулу с подстановками.
- Откройте блок «Досрочка или вклад»: сейчас выгоднее вклад, а при потере льготы выгоднее досрочка.
- Откройте сценарий «Потеря права на льготу» и посмотрите, как вырастет платёж.

**3. Жизнь после ипотеки** — `#/after`
- Гость видит демо-кредит или вводит свой.
- Нажмите «Войти» и выберите Анну Соколову (или откройте `#/after/cabinet?as=sokolova`). Данные подтягиваются из «банка». Сверху — срочное напоминание: подтвердить занятость через 12 дней. Ниже — остаток, график, досрочка тем же ядром, вычет до 447 427 ₽ и заказ справки.
- Игорь Лебедев (`?as=lebedev`): страховка заканчивается через 17 дней.

**4. Админка: новый сценарий за минуту** — `#/admin`, пароль `rshb2026`
1. «Сценарии и формулы» → «+ Новый сценарий».
2. Название «Рождение ребёнка», id `child-birth`, описание «Направить материнский капитал в досрочное погашение».
3. Параметр: имя `child`, подпись «Какой по счёту ребёнок», по умолчанию 1, минимум 1, максимум 5, шаг 1.
4. Формулы:
   - «Разовый досрочный платёж»: `child == 1 ? matCapFirst : matCapSecond`. Суммы маткапитала (728 921,90 ₽ и 963 243,17 ₽) — глобальные параметры, их правят на вкладке «Параметры».
   - «Месяц досрочного платежа»: `12`.

   Предпросмотр сразу показывает значение формулы и сокращение срока.
5. Ошибка для проверки: `matCapFirst + bonus` → «неизвестная переменная «bonus»», кнопка «Сохранить» неактивна.
6. «Сохранить» → «открыть в симуляторе»: сценарий появился в списке, его цифры кликабельны.

Этот сценарий проверяется автотестом ([src/modules/admin/admin.test.ts](src/modules/admin/admin.test.ts)).

## Честно о допущениях

- **Админка без настоящей авторизации.** Пароль — заглушка, он показан на экране входа. Изменения сохраняются в `localStorage` браузера, их можно экспортировать в JSON и сбросить к умолчаниям.
- **«Банковский контур» — имитация.** Три демо-клиента лежат в JSON. Остаток долга считается по графику, а не приходит из API банка. Даты сдвигаются так, чтобы напоминания всегда были актуальными.
- **Все ставки, цены и лимиты условные.** Это значения на октябрь 2026 по открытым источникам: сельская ипотека 3%, лимит 6 млн ₽, взнос от 30,01% в РСХБ, рыночная ставка около 18,7%, инфляция 6,4%. Правила налогового вычета и размер маткапитала стоит сверять с ФНС и СФР.
- **Обязательства по сельской ипотеке** (подтверждать работу каждые 6 месяцев в течение 5 лет, регистрация в доме) в демо отсчитываются от даты выдачи кредита.
- **Ссылки на сервисы экосистемы «Своё»** ведут на их публичные сайты. Интеграций нет.
